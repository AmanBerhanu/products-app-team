# Users Feature Wireframes

## login.html

- Page title: Login
- Username input
- Password input
- Login button
- Invalid login error message area
- Registration successful message area
- Logout successful message area
- Link to Register

## register.html

- Page title: Register
- Username input
- Password input
- Confirm Password input
- Register button
- Error message area
- Link to Login

## userAdmin.html

- Page title: User Administration
- Table of users
- Username column
- Role column
- Enabled column
- Edit button/link for each user
- Delete button/link for each user
- Navigation area
- Logout button

## editUser.html

- Page title: Edit User
- Display username
- Role selection
- Enabled checkbox
- Hidden user ID field
- Save Changes button
- Cancel/Back link
- Error or message area

## confirmDeleteUser.html

- Page title: Confirm Delete User
- Display username
- Display role
- Display enabled status
- Hidden user ID field
- Confirm Delete button
- Cancel/Back link
- Confirmation or error message area
